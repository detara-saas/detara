# Referências visuais aprovadas

As três pranchas desta pasta foram fornecidas e aprovadas pelo responsável pelo produto em 13/08/2026. Elas documentam marca, usos, cores, tipografia, temas, ícones e direção de interface.

Os arquivos em `src/Detara.Web/wwwroot/brand/` foram recortados diretamente dessas pranchas, sem geração ou redesenho. Como as fontes recebidas são pranchas rasterizadas de 1536×1024, os assets 512/1024 e o `.ico` são derivados provisórios. Para produção e lojas de aplicativos, devem ser substituídos pelos exports individuais originais, idealmente SVG/PNG em resolução nativa, preservando os mesmos nomes.
